# Checklist de página de site

## Argumento

- [ ] A página tem uma ação principal, com o mesmo rótulo no hero, no meio e no fim.
- [ ] Cada seção responde a uma pergunta do visitante, na ordem das perguntas.
- [ ] Lendo só o hero e os títulos, a página se entende.
- [ ] Nenhuma seção existe só para preencher; cada uma tem massa.
- [ ] A sequência não serviria para outra empresa trocando o nome.

## Primeira dobra

- [ ] Em 1280 x 800: título, frase, ação e foco do visual sem rolar.
- [ ] Em 390 x 844: título, frase e ação sem rolar.
- [ ] Em 1920 x 1080: container limitado e hero ainda cabe.
- [ ] Um `h1`, só no hero.
- [ ] O visual é o produto real, uma foto real ou tipografia.
- [ ] Sem selo, linha de versão ou lista de vantagens no hero.

## Conteúdo

- [ ] Todo texto, número, depoimento e logo é real; lacunas marcadas no viewspec.
- [ ] Cerca de 80 palavras por tela.
- [ ] Títulos de seção com seis palavras ou menos, sem rótulo acima.
- [ ] Nenhum fato repetido em quatro seções.
- [ ] Datas, números e moeda no formato do público.

## Seções

- [ ] Cada região usa um fragmento do catálogo, com a fonte no viewspec.
- [ ] Seções vizinhas diferem em fundo, composição ou alinhamento.
- [ ] Prova só com dado real.
- [ ] Preço e condições visíveis antes do clique.
- [ ] Perguntas respondem ao que impede a ação.
- [ ] A página fecha com a ação que o visitante veio fazer.

## Navegação

- [ ] Cabeçalho em uma linha, com a página atual marcada e a ação visível no celular.
- [ ] Link de pular para o conteúdo.
- [ ] Menu do celular com foco preso e Escape.
- [ ] Rodapé só com destinos reais.
- [ ] Nenhum link ou botão quebra linha.

## Tema e forma

- [ ] Só papéis do tema; fundos pelos presets do guia.
- [ ] Nenhum cartão dentro de cartão; borda ou sombra, nunca as duas.
- [ ] Texto sobre padrão ou imagem com contraste medido.
- [ ] Tema claro e escuro conferidos, quando o projeto tem os dois.

## Movimento

- [ ] Entrada no hero, revelação nas seções, hover nos cartões, do topo ao rodapé.
- [ ] No máximo um movimento contínuo por tela visível.
- [ ] Tudo visível sem JavaScript e com movimento reduzido.

## Técnica

- [ ] `lang`, `title` e descrição.
- [ ] Imagens com dimensões, texto alternativo e prioridade certa.
- [ ] Vídeos com fachada.
- [ ] Nenhuma rolagem horizontal de 320 a 1920 px.
- [ ] Endereço antigo com redirecionamento permanente, quando a página mudou de lugar.

## Fechamento

- [ ] Lista de vícios de página gerada passada, com piso corrigido e reflexos resolvidos ou justificados.
- [ ] Itens marcados no viewspec.
- [ ] Capturas de celular e desktop feitas para a `designfy-review`.
